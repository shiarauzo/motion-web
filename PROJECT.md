## Goal

Give an author a page where a catalog recipe or a pointer sketch becomes one
portable motion spec that can be copied to an agent and applied on a site they
control.

## Done when

- Bounce, spiral, and orbit play as looping previews and copy the same spec
  shape.
- A pointer sketch can be recorded, cleaned, looped, and copied as that spec.
- The copied spec describes motion only and does not name a target element.

## Current state

Catalog cards play live motion. A sketch shows its trail. Authors can preview
with their own image. The copied spec stays motion-only.

## Next action

Make the preview follow Spec time, then apply a copied spec on a real page.
